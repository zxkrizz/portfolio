    How I work

    01

    Everything is code, and code goes through a pipeline.

    Infrastructure lives in Terraform and ships with GitHub Actions — planned, reviewed and applied the same way every time. No portal clicks nobody can reproduce.

    02

    Golden paths, not gatekeeping.

    I package the approved way of doing things into reusable modules and workflows, so teams get a secure, tagged, policy-compliant Azure environment by default.

    03

    Built to heal itself.

    Redundancy, health checks and automation first; heroics last. Try it — click any pod in the cluster and watch the platform replace it.

    04

    Measured, not assumed.

    Grafana, Zabbix, Datadog and Wazuh across cloud and on-prem — alerting on what users actually feel instead of every CPU spike.

    05

    Accountable when it breaks.

    When something fails I fix it calmly, find the root cause, and automate it out of existence.
